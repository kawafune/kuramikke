# 事業者向けの営業スタイル（オンライン完結）案

> 状態：ドラフト（2026-10-27）。代表の方針：「営業の電話や訪問ではなく、短いLPなどで、オンライン完結できる状態をつくりたい」。
> 実装済みの下書き：`/business`（掲載のご案内。短いLPの形）、`/business/standards`（審査基準）。どちらも開発モードで見られる。

## 1. 方針
- 事業者が、ページを読んで、**自分で申し込める**状態にする（電話・訪問は不要）。
- 申込み → 審査 → 掲載内容の確認 → 契約・請求 → 掲載開始、までを、メールとオンラインで行う。
- 窓口は、**最初はメールアドレス**。いずれは、**お問い合わせフォーム → AI＋人間**で対応する。
  - メールアドレスは、**公開のリポジトリには書かない**（営業メールを避けるため）。環境変数 `VITE_CONTACT_EMAIL` から読む。
    - 本番：Vercel の Settings → Environment Variables に `VITE_CONTACT_EMAIL` を登録して、再デプロイする。
    - 設定するまでは、ボタンの代わりに「準備中」と表示される。書き方の見本は `.env.example`。
  - 画面には、アドレスの文字は出さない（ボタンを押したときだけ、メールの作成画面が開く）。ただし、ページを読み込む人には、ボタンの宛先が見えるため、**完全に防げるわけではない**。将来は、お問い合わせフォームに切り替える。

## 2. 掲載料（仮案。【要人間確認】）
| | 金額（税込） | 最低掲載期間 | 備考 |
|---|---|---|---|
| 標準プラン | 月額 11,000円 | 6か月 | 1分野に掲載 |
| 募集開始の特典 | 月額 5,500円（標準の半額） | 6か月 | 先着○社・○年○月末まで。掲載開始から6か月間 |

- **相場は、私は確認できていない。**代表が、同じ分野の掲載サイト（葬儀社の紹介サイトなど）の掲載料を、いくつか調べて、金額を決める。
- アクセス実績がまだ無いため、標準の金額を高くしない。特典は「実績がない間の、先行掲載のお礼」と位置づける。
- **「割引」ではなく「募集開始の特典」と書く。**標準の金額で実際に掲載する期間がない状態で「通常○円のところ…」と書くと、二重価格表示（実際に売っていない価格との比較）になるおそれがある。特典の期間と、標準に戻る時期を、はっきり書く。【要専門家確認】
- 「問い合わせや契約の件数を保証するものではない」と、必ず書く（実装済み）。

## 3. 申込みから掲載までの流れ（オンライン）
1. メールで申込み（ひな形つき：会社情報、分野、許可・資格の番号、サイトのURL）
2. 審査（`/business/standards` の基準で、公開情報を確認）
3. 掲載内容の確認（メールでやり取り）
4. 契約・請求（掲載規約への同意 → 請求書 → 銀行振込）
5. 掲載開始

### 決めること・用意すること
| 項目 | 内容 |
|---|---|
| 掲載規約（契約の条件） | 掲載の取りやめ、返金、禁止事項、責任の範囲など。**弁護士に確認**【要専門家確認】 |
| 請求書 | 発行の方法。適格請求書（インボイス）の登録の有無を確認【要確認】 |
| お支払い | 最初は銀行振込（請求書）が簡単。クレジットカード決済（Squareなどの請求書機能）は、あとから検討 |

## 4. 事業者を見つける方法（電話なし）
- 公開されている情報から、候補の事業者を調べる（葬儀社、霊園、遺品整理など）。
- メールや、会社のお問い合わせフォームから、`/business` のご案内を送る。
  - **営業のメールは、法律（特定電子メール法）の決まりがある**（送信者の表示、配信停止の方法など）。事業者宛でも対象になる場合がある。**送る前に、専門家に確認する**【要専門家確認】。
- 紹介してくださる方がいれば、そのご縁も使う（Happiinoの既存のつながり）。
