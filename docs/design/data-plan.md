# 病院・老人ホームのデータ方針（ドラフト）

> 状態：ドラフト（2026-10-25）。決定事項は代表の回答に基づく。

## 決まっていること
- データは**公的な公開データ**を使う。民間の検索サイトのスクレイピングはしない（利用規約・著作権のリスクのため）。
- そのあと、各施設に声をかけ、施設自身の情報（写真・特徴・営業時間など）を追加してもらう。
- 対象は**まず病院**。老人ホームは次の段階（参考：「みんなの介護」）。
- 地図は病院・老人ホームで**同じ部品**（`src/components/search/FacilityMap.jsx`）を使う。いまは仮の地図。「ちぃくり」のマップ機能は、改善してから載せ替える。

## 元データの候補（【要確認】最新の利用条件・提供形式）
| 対象 | 候補 |
|---|---|
| 病院 | 厚生労働省「医療情報ネット（ナビイ）」のオープンデータ |
| 老人ホーム | 厚生労働省「介護サービス情報公表システム」のオープンデータ（有料老人ホーム等） |

## 画面に必ず出すもの
- 出典と取得日（`data/hospitals.js` の `DATA_SOURCE`）
- 「受診前に各医療機関へご確認ください」の注意書き

## 取り込み後の形（`data/hospitals.js` の項目）
`id / name / prefecture / address / tel / departments[] / hours / holiday / lat / lng`
- 位置情報（lat/lng）が元データにない場合は、住所から変換する作業が別途必要【要確認】。
- 個人名（代表者名など）は取り込まない。

## 今後の作業（案）
1. 元データの形式と利用条件を確認する（代表）
2. 取り込みスクリプトを作り、`hospitals.js` と同じ形に変換する
3. 件数が多い場合は、検索を画面側ではなくサーバー側に移す
4. 老人ホームの項目（種別、費用、入居条件など）を設計する
5. 掲載依頼から、施設自身の情報を追加できるようにする

## 進捗（2026-10-27）
原案07〜09に沿って、病院検索の3画面を、仮データで作った（開発モードのみ。`/search` → `/search/results` → `/hospitals/:id`）。
- 検索TOP：病院／老人ホームの切替（老人ホームは準備中）、掲載数、キーワード、エリア（地方別）、診療科目
- 検索結果：選択中の条件（×で外せる）、条件の追加（夜間・休日・女医・駐車場・カード可）、再検索（曜日・時間）、ページ送り、地図で見る
- 病院詳細：診療科目、最寄り駅、診療時間の表、休診日、所在地、地図
- 条件はURLに持つ（共有、戻るボタンが使える）
- 地図は仮のまま。病院と老人ホームで同じ部品を使う

### まだ作っていないもの（原案にあるが、公的データには無い／ログインが必要）
- 写真、お知らせ、診療案内、医師紹介、求人情報 → 施設からの掲載申込みで追加する部分
- お気に入り、ネット予約、閲覧履歴 → ログインや外部連携が必要
- 路線から探す → 路線データが必要

### 次に必要なこと
1. 公的データの形式と利用条件を確認する（代表）→ 取り込みの設計
2. 位置情報（緯度・経度）の取得方法
3. 件数が多くなったときの検索（いまは画面側で計算している）
4. 老人ホームの項目の設計
