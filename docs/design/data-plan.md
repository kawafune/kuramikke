# 病院・老人ホームのデータ方針（ドラフト）

> 状態：ドラフト（2026-10-25）。決定事項は代表の回答に基づく。

## 決まっていること
- データは**公的な公開データ**を使う。民間の検索サイトのスクレイピングはしない（利用規約・著作権のリスクのため）。
- そのあと、各施設に声をかけ、施設自身の情報（写真・特徴・営業時間など）を追加してもらう。
- 対象は**まず病院**。老人ホームは次の段階（参考：「みんなの介護」）。
- 地図は病院・老人ホームで**同じ部品**（`src/components/search/FacilityMap.jsx`）を使う。いまは仮の地図。「ちぃくり」のマップ機能は、改善してから載せ替える。

## 元データの候補（【要確認】最新の利用条件・提供形式）
| 対象 | 候補 |
|---|---|
| 病院 | 厚生労働省「医療情報ネット（ナビイ）」のオープンデータ |
| 老人ホーム | 厚生労働省「介護サービス情報公表システム」のオープンデータ（有料老人ホーム等） |

## 画面に必ず出すもの
- 出典と取得日（`data/hospitals.js` の `DATA_SOURCE`）
- 「受診前に各医療機関へご確認ください」の注意書き

## 取り込み後の形（`data/hospitals.js` の項目）
`id / name / prefecture / address / tel / departments[] / hours / holiday / lat / lng`
- 位置情報（lat/lng）が元データにない場合は、住所から変換する作業が別途必要【要確認】。
- 個人名（代表者名など）は取り込まない。

## 公的データ（医療情報ネット）の確認結果（2026-10-28）

対象：`01-1_hospital_facility_info_20250601.csv`（病院の施設票。7,587件・65列・UTF-8 BOM付き）

| 項目 | わかったこと |
|---|---|
| あるもの | ID、正式名称・フリガナ・略称、所在地、緯度経度、ホームページ、曜日・週ごとの診療フラグ、祝日、年末年始などの休診日、病床数 |
| **ない**もの | **電話番号**、診療科目、診療時間、最寄り駅 → 診療科・時間票（01-2）か、別の項目に入っている可能性【要確認】 |
| 質問の列名は「休診」だが、値は「診療あり＝1」と読める | 日曜は0が6,928件、祝日は0が7,130件。病院の実態と合うため、1＝診療ありと推定【要確認：項目定義書】 |
| 座標 | 270件が 0.0（未登録）→ 地図に出さない |
| ホームページ | 310件は空 |
| 文字 | 住所・名称に全角の数字や英字が混ざる → 検索用に半角へそろえる（NFKC） |
| 規模 | 病院7,587件。診療所は約10万件規模の見込み（ファイルが約100MB）→ 診療所は別方式にする |

取り込み方針：病院は都道府県ごとのJSONに分け、画面で必要な県だけ読み込む（生データはリポジトリに入れない）。診療所は、データベース方式を検討。ライセンスは CC BY のため、出典表示が必要。

### 取り込みの手順と状況（2026-10-28）

- Googleドライブ「公的Data」に、01-1〜05 のCSVがある（診療所 02-1・02-2 も含む。電話番号は、どのファイルにも無い）。
- 変換スクリプト：`scripts/import_medical.py`（標準ライブラリのみ）。施設票＋診療科・時間票を、都道府県ごとのJSONにする。
  診療時間は、全診療科の「外来受付」時間をまとめて、画面の表（時間帯の行×月〜祝）の形にする。
- 動作確認：01-1（病院7,587件）で変換できた。01-2は、先頭の数行だけで確認（全体は未確認）。病院のみで約3.5MB（診療時間を除く）。
- 診療日の列：値は「診療あり＝1」と推定。01-2の先頭（札幌医科大学附属病院：内科 月〜金 9:00〜）と一致【項目定義書で最終確認】。
- 診療所は約10万件。県ごとのJSONでは大きすぎる（東京だけで10MB超の見込み）→ 市区町村ごとに分ける、またはデータベース（Supabase等）にする。
- 電話番号が無い → 公式サイト・Googleマップへの導線を主にする。電話は、施設の掲載申込みで追加する。

### 実データを画面につないだ（2026-10-28）

- `public/data/medical/NN.json`（47県＋index.json、約48MB。配信時は圧縮され、東京で約1.1MB）を、見る県だけ読み込む。
  病院7,587件＋診療所75,254件＝82,841件（基準日：2025-06-01）。診療科・時間が登録されているのは 病院7,492件 / 診療所73,483件。
- **データベース（Supabase）は、検索には不要になった**（県ごとのファイルで足りる大きさだったため）。
  必要になるのは、施設の「掲載情報」（写真・電話番号・お知らせ）、掲載申込み、お問い合わせフォームなどを保存するとき。
- 画面の変更：電話番号と最寄駅の表示をやめ、公式サイトとGoogleマップへの導線に。特徴は、時間から計算できる「夜間も受付（19時以降）」「日曜・祝日も受付」だけ。
  検索は、エリア（都道府県）の選択が必須。診療科は、多い20種を選択肢に（全部で約1,100種。ほかはキーワード）。
- 更新（年1回）：新しいCSVを `scripts/import_medical.py` で変換し、`public/data/medical/` と `DATA_ASOF`（src/data/medical.js）を差し替える。
- 【要確認】座標が無い施設 4,456件は、地図に出さない。公式サイトが無い施設 28,588件。

## 介護サービス情報公表システムのオープンデータ（2026-10-29）

- 取得元：厚生労働省 [介護サービス情報の公表システムデータのオープンデータ](https://www.mhlw.go.jp/stf/kaigo-kouhyou_opendata.html)。2026年6月末時点（出力日 2026-07-09）。サービスごとのCSV（`jigyosho_<コード>_all_*.csv`）。
- 項目（24列）：事業所番号、名称・カナ、サービスの種類、住所、緯度経度、**電話番号**、FAX、法人名、URL、利用可能曜日、定員。
  確認した3ファイル（110訪問介護・120訪問入浴・130訪問看護、計55,141件）は、電話番号が100%、座標が99.9%、URLが65%。
- **費用（入居一時金・月額）や空き状況は、入っていない。**
- **老人ホーム検索に使うサービスコード**：331（介護付き有料）、332（軽費）、334（サ高住・特定施設）、320（グループホーム）、510（特養）、520（老健）。必要に応じて 335〜337・361〜364・530・540・550。
- **入っていないもの**：住宅型有料老人ホーム、介護保険の特定施設ではないサ高住。→ 別の公表データ（自治体の有料老人ホーム情報、国交省のサ高住情報提供システム）が必要。
- 訪問介護・訪問看護（110・130）などは、「ご家族の在宅介護」向けの検索として使える可能性がある（電話番号つき）。
