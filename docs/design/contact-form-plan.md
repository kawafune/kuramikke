## 方針（2026-11-03 に確認）
- **クラミッケは、利用者の個人情報を、事業者に渡さない。** 介護施設への「資料請求・見学申し込み」を、クラミッケのフォームから事業者へ送る形は、いまは作らない。
  （デザインPDFのタイトルは「お問い合わせ・介護施設資料請求・見学申し込みフォーム」。当面は「お問い合わせ」だけ作る）
- 専門家に伝わっていた「事業者へ提供する」条項は、誤りだったため、プライバシーポリシー・各ページの広告欄から外した。

## 作り方の案（お問い合わせだけ）
| 項目 | 案 |
|---|---|
| 画面 | デザインどおり、入力 → 確認 → 完了の3ステップ。入力項目：お名前、メールアドレス、お問い合わせの種類（ご利用・掲載内容の誤り・事業者の方・個人情報・その他）、内容。同意のチェック（プライバシーポリシー） |
| 送信 | Vercelのサーバー機能（Function）から、メール送信サービス（Resendなど）で、運営のメールに送る。データベースは、使わない（保存しない） |
| 迷惑送信への対策 | 見えない入力欄（ハニーポット）、送信回数の制限、必要ならCloudflare Turnstile |
| 自動返信 | 受付のお知らせメールを、送信者に返す |
| 必要な準備（代表） | 独自ドメインの設定後、メール送信サービスのアカウント作成と、ドメインの認証（DNS）。送信先のメールアドレス |
| プライバシーポリシー | 「お問い合わせの内容は、メール送信サービス（委託先）を通じて、運営が受け取る」旨を追記【要専門家確認】 |
