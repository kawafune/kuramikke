# お問い合わせフォーム（案）

> 状態：**実装済み（2026-11-04）。まだ公開していない（開発モードでだけ見える）。** 公開には、下の手順が必要。
> デザインPDF（`05_..._form.pdf`：入力→確認→完了の3ステップ）を受領。いまは、メール方式（/contact）で公開中。

## 方針（2026-11-03 に確認）
- **クラミッケは、利用者の個人情報を、事業者に渡さない。** 介護施設への「資料請求・見学申し込み」を、クラミッケのフォームから事業者へ送る形は、いまは作らない。
  （デザインPDFのタイトルは「お問い合わせ・介護施設資料請求・見学申し込みフォーム」。当面は「お問い合わせ」だけ作る）
- 専門家に伝わっていた「事業者へ提供する」条項は、誤りだったため、プライバシーポリシー・各ページの広告欄から外した。

## 作り方の案（お問い合わせだけ）
| 項目 | 案 |
|---|---|
| 画面 | デザインどおり、入力 → 確認 → 完了の3ステップ。入力項目：お名前、メールアドレス、お問い合わせの種類（ご利用・掲載内容の誤り・事業者の方・個人情報・その他）、内容。同意のチェック（プライバシーポリシー） |
| 送信 | Vercelのサーバー機能（Function）から、メール送信サービス（Resendなど）で、運営のメールに送る。データベースは、使わない（保存しない） |
| 迷惑送信への対策 | 見えない入力欄（ハニーポット）、送信回数の制限、必要ならCloudflare Turnstile |
| 自動返信 | 受付のお知らせメールを、送信者に返す |
| 必要な準備（代表） | 独自ドメインの設定後、メール送信サービスのアカウント作成と、ドメインの認証（DNS）。送信先のメールアドレス |
| プライバシーポリシー | 「お問い合わせの内容は、メール送信サービス（委託先）を通じて、運営が受け取る」旨を追記【要専門家確認】 |

## 決めること
1. 独自ドメイン（kura-mikke.com）の切り替え後に、進めてよいか（推奨：はい。送信元のメールにもドメインが必要なため）
2. 将来、施設への資料請求・見学申し込みを作るか（作る場合は、利用者の同意と、プライバシーポリシーの見直しが必要）

## 公開の手順（代表）
1. 独自ドメイン kura-mikke.com を、Vercelに設定する
2. メール送信サービス [Resend](https://resend.com/) のアカウントを作り、ドメイン（kura-mikke.com）を認証する（DNSに、Resendが指示する数行を追加）。APIキーを発行する
3. Vercel の環境変数（Production）に登録する：`RESEND_API_KEY`（APIキー）、`CONTACT_TO`（受け取るメールアドレス）、`CONTACT_FROM`（例：`クラミッケ <noreply@kura-mikke.com>`）、`VITE_CONTACT_FORM`＝`1`
4. 再デプロイして、フォームから、自分あてにテスト送信する
5. **公開の前に、プライバシーポリシーに追記する**（専門家の確認）：お問い合わせの内容は、メール送信サービス（Resend, Inc.）を通じて当社が受け取る旨と、保管（当社のメール）についての書き方

## 実装の内容
- 画面：`src/components/ContactForm.jsx`（入力 → 確認 → 完了）。`VITE_CONTACT_FORM=1` のとき、または開発モードで、/contact に出る。出ないときは、メール方式のまま。
- 送信：`api/contact.js`（Vercelのサーバー機能）。入力の確認、見えない欄（ハニーポット）、表示から3秒以内の送信を捨てる、同じ接続元から10分に5回まで、運営へのメール（返信すると送った方に届く）、送った方への受付メール。保存・ログ出力はしない。
- 迷惑送信が増えたら：Cloudflare Turnstile を足す（無料）。
