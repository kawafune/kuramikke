## 1. コンセプト（企画書より）

- **理念**：親の引退・死、子どもの誕生、自身の将来への希望と不安を、日々身近に感じ始める「真っ只中の世代」に寄り添う。シニア世代へ「生（活）きがい」をつくる機会を届ける。
- **4本柱をワンストップで**
  1. 身近な施設情報（病院・介護施設の比較）
  2. コラム（正しく信頼できるお役立ち情報）
  3. 絆を見つける（旧：出逢い。コミュニティ・イベント）
  4. 終活サポート（エンディングノート・自分史＝「ご自身の1冊の本をつくる」）
- **使う人（3層）**
  - ① 定年を控えた世代（50代〜65歳）：PC・スマホに慣れている
  - ② 既に引退した世代（65歳以上）：タブレットなどに触れるきっかけになる
  - ③ 上記の親を持つ子世代（20代後半〜45歳くらい）
- **収益**：広告掲載、施設情報掲載（原案では掲載料・年間費とも無料をうたう）、既存サービスへの送客【要人間確認：料金方針】
- **マインドマップにあって原案16枚にない機能**：家族用の生存確認ボタン（災害時）。今回の対象外として扱う。

## 2. デザイン原則（原案から読み取れること）

1. **ゴールド1色＋クリームの濃淡**でまとめる。色の賑やかさは写真とイラストで出す。
2. **フラットで枠線中心**。影やぼかしは使わない。角丸はボタンの小さな丸みだけ。
3. **白とクリームの帯を交互に重ねる**ことで、セクションを区切る。
4. **見出しはゴールドの中央揃え**にして、下に短い下線を引く。どのページでも同じ形にする。
5. **文字間を広く**とる（およそ0.1em）。ゆったりとやさしい印象にする。
6. **押せるものは見た目で分かる**ようにする。ボタンの下側に濃い影線を入れ、矢印アイコン（⊕→）を添える。

### 3-3. 読みやすさの課題と調整案（2026-10-25 決定：ボタンは案A）

文字と背景のコントラスト比を計算しました。WCAG（ウェブの読みやすさの国際基準）のAA基準は、通常の文字で4.5:1以上です。

| 組み合わせ | 比 | 判定 |
|---|---|---|
| 本文 `#4C4C4C` / 白 | 8.6 | ◎ |
| ゴールド文字 `#CCAD30` / 白 | **2.2** | ✕ |
| ゴールド文字 / クリーム | **2.0** | ✕ |
| 白文字 / ゴールドボタン | **2.2** | ✕ |
| 白文字 / 体験型 `#99CDF5` | **1.7** | ✕ |
| 白文字 / 参加無料 `#E44D32` | 3.9 | △（大きい文字ならOK） |

ゴールドの文字は、シニアの方には特に読みにくくなります。そこで、**面と線は原案のゴールドのまま残し、文字だけ濃くする**案です。

| 用途 | 案 | 比 |
|---|---|---|
| 見出し・リンクの文字 | 濃ゴールド `#8A6D0B` | 白で4.9、クリームで4.6 |
| ボタン（案A） | 面 `#8A6D0B` ＋ 白文字 | 4.9 |
| ボタン（案B） | 面 `#CCAD30` ＋ 濃い文字 `#333333` | 5.8 |
| 淡い色の特徴タグ | 文字を白から同系の濃色へ変える | 色ごとに調整 |

### コラム
- **TOP**：ヒーロー →（本文列）横型の記事行、ページ送り ／（サイドバー）カテゴリ、ランキング、最新、キーワード
- **記事詳細**：大きな写真、タイトル（中央）、リード、カテゴリと関連キーワード、公開日 → 本文（写真に出典、サブ見出し）→ この記事のキーワード → 関連記事（2列）
- **タグ一覧**：タグ名、関連記事の件数、関連タグ → 記事行

### 出逢いを探す
- **TOP**：ヒーロー → キーワード検索（性別・エリア・特徴・日付、「この条件で検索する」）→ 新着イベント → おすすめイベント → まもなく定員 → 特徴一覧

- **イベント応募**：ログイン導線 ＋ 会員登録なしの応募フォーム（氏名、フリガナ、生年月日、電話、メール、支払い方法）【要人間確認：個人情報の取得項目】
- **新着イベント一覧**：イベントカード3列、ページ送り

### 終活サポート
- **TOP**：ヒーロー → 終活とは（二重枠の要点リスト付き）→ バナー（注記「相談の窓口のスタッフは法律の専門家ではない」）→ クラミッケとしての考え → エンディングノートとは（クリーム帯）→ 広告枠3つ
