# 独自ドメイン（kura-mikke.com）への切り替え手順

> ドメインは、ムームードメインで取得したもので問題ありません（ドメインの管理場所と、サイトの置き場所は、別でよい）。
> いまの kura-mikke.com には、旧ページ（運営会社紹介）が載っている。切り替えると、そのページは見えなくなる。

## 先に確認すること（5分）
1. **旧ページの置き場所**：ムームーサーバーなどのレンタルサーバーか、別のサービスか。切り替えのあとも使うものが無いか（他のページ・メール）。
2. **メールの有無**：@kura-mikke.com のメールを、使っているか。使っている場合は、**ネームサーバーは変えず**、「DNSの記録（レコード）」だけを変える。（ネームサーバーを変えると、メールが止まることがある）
3. **ネームサーバーの場所**：ムームードメインの「ドメイン操作 → ネームサーバ設定変更」で、いまの設定を確認する。
   - 「ムームーDNS」を使っている → ムームーDNSで、レコードを設定（下の手順）
   - レンタルサーバー側のネームサーバーを使っている → そのサーバーのDNS設定で、レコードを設定

## 手順
1. **Vercel**：プロジェクト → Settings → Domains → `kura-mikke.com` を追加。`www.kura-mikke.com` も追加して、「kura-mikke.com へリダイレクト」にする。画面に、必要なDNSのレコードが出る（以下は一般的な値。Vercelの画面に出た値を使う）
   - `kura-mikke.com`（ルート）：種別 A、値 `76.76.21.21`
   - `www`：種別 CNAME、値 `cname.vercel-dns.com`
2. **ムームードメイン**：コントロールパネル → ドメイン操作 → ムームーDNS → 「セットアップ情報変更」→ 上のレコードを追加。（旧ページ向けの、ルートのAレコードがあれば、置き換える）
3. 数分〜数時間（最大で1日ほど）待つ。Vercelの画面が「Valid Configuration」になれば完了。HTTPSの証明書は、自動で付く。
4. **サイト側の切り替え**（Claude）：`HOME='portal'`、`READY.SEARCH=true`、公開表示の巡回、sitemap・robots の確認。
5. **そのあと**：Google アナリティクスの設定 → Search Console（サイトマップの送信）→ Resend（フォーム）→ ASP申請。

## 切り替え前の準備（旧ページを残したいとき）
- 旧ページのHTMLをバックアップしておく。必要なら、`/old` などで公開する、または、運営会社ページに内容を移す。
